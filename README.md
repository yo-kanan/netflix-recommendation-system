# 🎬 Netflix Recommendation System

## 📌 Project Overview
This project builds a content-based recommendation system for Netflix movies and TV shows using machine learning techniques. The system suggests similar content based on metadata such as genre, description, and cast.

---

## 🛠 Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- NLP (Natural Language Processing basics)  
- Jupyter Notebook  

---

## 📂 Dataset
Netflix dataset sourced from Kaggle containing movies and TV shows with features like title, genre, description, cast, and rating.

---

## 🔍 Project Workflow
- Data Cleaning and Preprocessing  
- Handling missing values  
- Text processing on descriptions  
- Feature extraction using vectorization  
- Similarity calculation using cosine similarity  
- Building recommendation function  

---

## 🤖 Recommendation Technique
- Content-Based Filtering  
- Cosine Similarity between movie descriptions  
- Feature vectorization using text data  

---

## 📊 Key Features
- Recommends similar movies based on user selection  
- Works on metadata (not user history)  
- Fast and efficient recommendation system  

---

## 🚀 Objective
To build a recommendation system that suggests similar Netflix content using machine learning and natural language processing techniques.

---

## 📈 Learning Outcomes
- Learned basics of recommendation systems  
- Understood text vectorization techniques  
- Applied cosine similarity for ranking content  
- Improved data preprocessing skills
